# Solace Mobile

React Native and Expo app for the mobile assignment. The repository root contains the Next.js prototype.

## Start

```sh
cd mobile
npm install
npm start
```

Open the project with a compatible Expo client or emulator.

The first native milestone is the branded opening screen, three onboarding steps, and a Home preview. The flow starts again on a fresh launch until account and onboarding persistence are implemented.
